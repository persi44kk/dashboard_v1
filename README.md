# Прототип интерфейса Info/RPF

### О проекте
Это визуальный прототип сервиса, созданный для демонстрации улучшений UX. 
**Цель:** Показать оптимальную компоновку элементов.

### Что реализовано:
- **Главный экран:** Улучшенная навигация и быстрый доступ к основынм функциям.
- **Компонент Customer Summary:** Переделан из таблицы в современное решение для снижения когнитивной нагрузки на оператора и ускорения принятия решения по счету.
- **Логика:** Основной фокус на сокращении кликов при постоянных действиях и исключение возможности ошибки и финансовых потерь.

### Технологический стек
- React + Tailwind CSS
- UI-библиотека: shadcn/ui
- Сгенерировано в v0.dev
